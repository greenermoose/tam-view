# P2 — Render markup for text terminals

Status: planned for 0.2.x, following the text milestones in P1.

Raw mode shows the source and is the default. Add a render mode that
turns Markdown and HTML into headings, lists, paragraphs, code, links
and tables suited to the available terminal width. Render Mermaid
flowcharts with labels, nodes and connections. Provide an ASCII
layout for the kernel console.

Feed rendered text to the pager so that paging, searching, and the
exit behavior carry over. Define supported markup and diagnostics
against sample documents during design of the rendering phase.
